# Ночная сводка

`mf_summarize` сводит завершённую ночную сессию по переданным потокам пульса, SpO₂ и размеченным интервалам стадий. Все метки — секунды UTC. Интервал [начало, конец) может пересекать полночь. Для обнаружения ночи, локального времени и чтения сенсоров нужны соответствующие адаптеры.

- Пульс и SpO₂ усредняются по принятым измерениям внутри всей ночной сессии, включая зарегистрированные пробуждения. `mean_x10` — среднее с одним десятичным разрядом. Поле `n` отличает отсутствие данных от числового значения.
- Проверяется признак пригодности записи. Пульс принимается от 1 до 254 в принятом однобайтовом протоколе. SpO₂ принимается от 1 до 100. Значение 255 зарезервировано. Это ограничения представления данных. Достоверность контакта с кожей должен подтверждать адаптер.
- Для SpO₂ доступны минимум, количество измерений строго ниже выбранного порога и длительность покрытия таких измерений. Каждое наблюдение покрывает интервал до ближайшей из трёх границ: следующей записи (в том числе непригодной), конца сессии или истечения переданного интервала удержания. Длительность покрытия — оценка по дискретным записям. `max_gap_s` показывает самый длинный интервал без покрытия. Частоту опроса указывает адаптер.
- Длительность сна равна сумме Light, Deep и REM. Время бодрствования и интервалы с неизвестной стадией возвращаются отдельно. Незаполненное время остаётся неизвестным. Выход содержит суммарную длительность каждой стадии и самый длинный неизвестный интервал.
- Порядок времени строгий внутри каждого потока. Дубликаты, перекрытия стадий и обратный порядок приводят к диагностическому результату. Адаптеру следует объединять повтор одного и того же исходного события до вызова.
- Функция работает за линейное время, не выделяет память, не изменяет вход. Один и тот же набор записей всегда даёт один и тот же итог.

## Проверка

Из каталога `core`:

```sh
gcc -std=c11 -O2 -Wall -Wextra -Wconversion -Werror -pedantic -fsanitize=undefined morning_summary.c test_morning.c -o /tmp/morning-test
/tmp/morning-test
zig cc -target thumb-freestanding-eabi -mcpu=cortex_m4 -Oz -std=c11 -ffreestanding -fno-builtin -fno-stack-protector -nostdlib -Wl,-e,mf_summarize morning_summary.c -o /tmp/morning-thumb.elf
python check_arm.py /tmp/morning-thumb.elf
```

Последний тест требует пакет Python `unicorn`. Оба теста успешно выполнены. В ARM-тесте скомпилированная функция вернула средний пульс 70,0, среднее SpO₂ 94,0 и 10 секунд неизвестных стадий на синтетической сессии, пересекающей полночь. В испытаниях использован Zig 0.13.0. У Cortex-M4 объектного файла отсутствуют неопределённые символы, секции data/bss пусты. Для выполнения на браслете по-прежнему требуется передать реальные завершённые записи.
