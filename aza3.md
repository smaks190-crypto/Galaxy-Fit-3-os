# Утренняя сводка на Galaxy Fit3

Проверка относится к SM-R390 и прошивке R390XXU0AZA3. В штатном образе подтверждены три источника для главного экрана. Для утверждения «за время сна» понадобятся временные метки и история наблюдений внутри завершённого эпизода сна.

## Данные штатного циферблата

| Показатель | Что подтвердил код AZA3 | Что может вывести сводка |
|---|---|---|
| Сон | Pair 104 считывает 16-битное значение в минутах. При значении 0xFFFF в поле записи +0x2C делит его на 60 и вычисляет остаток. Дуга 104 использует шкалу до 720 минут. | Продолжительность, которую отдаёт прошивка. Для подписи «за последнюю ночь» нужно проверить границы эпизода. |
| SpO₂ | Pair 102 проверяет флаг доступности и считывает 8-битное значение. При отсутствии замера штатный вывод — два дефиса. | Последнее доступное значение в процентах. Чтобы вывести ночной минимум или среднее, нужны замеры с датой и временем. |
| Пульс | Источник 41 хранит флаг наличия и число ударов в минуту. Штатная дуга использует верхнюю границу 220. | Последний доступный пульс. Ночной диапазон можно вычислить по измерениям внутри выбранного эпизода. |

Штатный формат длительности зависит от режима Pair. Русский языковой пакет AZA3 содержит латинские единицы h и m. При режиме 1 получаются строки «5m», «7h5m» и «12h59m». При режиме 2 обработчик выбирает вариант с пробелом или переносом строки. Ноль в поле длительности сам по себе не различает отсутствие сна и отсутствие данных.

## Основание проверки

SHA-256 распакованного образа main — 3c579693ceba6faff72598ebb4b828b3d54562411794293d2cb9f60693e6cdf0. Адреса ниже приведены для отображения образа по базе 0x2C080000. Версии с иной компоновкой требуют повторной проверки.

| Участок | Наблюдение |
|---|---|
| 0x2C1030B8 | Возвращает указатель на текущие данные циферблата. Для этой сборки его значение — 0x2010B190. |
| 0x2C103496, 0x2C10349A | Код обновления записывает флаг наличия пульса и значение в байты +0x79 и +0x7A. |
| 0x2C10221C, 0x2C1034B2 | При чтении данных сна используется запись 0x21E. Первый результат попадает в поле +0x7C. Есть также путь обновления этого поля по событию. |
| 0x2C106F4C, 0x2C106F98 | Обработчик Pair 104 и деление с остатком на 60. При длительности меньше часа выводятся только минуты. |
| 0x2C1034CC, 0x2C1034D0, 0x2C106E06 | Запись флага и значения SpO₂ в +0x7F и +0x80. Pair 102 выводит число либо строку «--» из ROM. |
| 0x2C105262 | Обновление нативной дуги. Для 41 верхняя граница 220, для 104 — 720. |

## Интеграция утренней сводки

Для сводки на телефоне в исходниках Fit3 App уже есть эпизоды сна с началом и окончанием, стадии сна и временные метки измерений. По протоколу синхронизации пульс имеет тип 10, SpO₂ — 112, эпизод сна — 16, стадии — 17. Код хранит историю поступивших измерений. Эти идентификаторы относятся к протоколу синхронизации. В циферблате используются идентификаторы из таблицы выше.

Для расчёта можно выбрать завершившийся эпизод, отобрать измерения по его временному интервалу и указать число полученных замеров. При единственном замере достаточно показать его значение и время. Пустая выборка означает «нет замеров за этот сон». Fit3 App умеет объединять перекрывающиеся интервалы и исключать бодрствование при полной непротиворечивой разметке стадий. Если разметка неполна, код использует длительность всего эпизода. Это различие важно сохранять в подписи.

Нуждаются в проверке на браслете: полнота истории ночного SpO₂ и пульса для конкретных настроек измерений, момент обновления итогов после пробуждения, поведение после дневного сна и перехода через полночь. Нативный экран пользовательской утренней сводки и его автоматический запуск этими чтениями не подтверждены. Изменений в прошивку не вносилось.
