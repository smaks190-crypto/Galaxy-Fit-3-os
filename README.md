# Galaxy Fit3 OS

Разработка для Samsung Galaxy Fit3 (SM-R390), целевая версия R390XXU0AZA3.

`core/` — расчёт утренней сводки. `ui/` — экран и график фаз. `aza3.md` — исследование данных прошивки. `watchface/` — штатный циферблат Vitals Refined, отдельный от модуля утренней сводки.

Утренний отчёт предназначен для завершённой сессии сна. При отсутствии надёжных измерений поле остаётся пустым. Экран с демонстрационными записями служит для проверки компоновки. Подключение к сервисам браслета и сборка устанавливаемого обновления ОС требуют проверки интерфейсов AZA3.
